# GTV 房源特征与关联质量（脱敏聚合）

> 演示种子 · `[template:gtv_deal]`

## 房源主体

| 类型 | 主表角色 | 签约挂载说明 |
|------|----------|--------------|
| 厂房 | 厂房基础档案 + 租金表 | 与签约明细按房源 ID 关联，接合率约 99% |
| 仓库 | 仓库基础档案 + 租金表 | 接合率约 100% |
| 办公 | 优先房间档案（非楼栋） | 房间接合率约 97%；楼栋接合不可靠 |

## 常用特征（建模侧）

- 城市 / 区域（聚合编码，非详细地址）
- 跟进次数、带看次数（热度；库内多为当前快照，存在时间泄漏风险）
- 上下架状态（当前态，历史上下架事件不可可靠还原）
- 租金/售价区间、录入时间相对 T0 的房龄
- 业态类型（厂房 / 办公 / 仓库）

## 标签定义

| 问题 | 正样本 | 负样本近似 |
|------|--------|------------|
| 房源是否成交 | 签约明细审批通过 | 录入早于 T0 且 T0 前未成交 |
| 租或售 | 签约类型映射 | — |
| 成交时间 | 合同时间优先，否则签约创建时间 | 未成交右删失 |

## 能力边界（写入本体供推演约束）

- 操作日志未见稳定上架/下架事件类型，故「T0 时在架」无法严格重构。
- 热度字段为当前快照时，解读以相对排序为主。
- 历史约一年、正样本约千级；部分早期折可能使用 within-fold holdout。
