# GTV 经纪人与开单归因（脱敏聚合）

> 演示种子 · `[template:gtv_deal]`

## 经纪人主体

经纪人来自系统用户主档（非瘦表），关联门店/团队。  
演示不暴露手机号、证件号；实体以「经纪人 / 门店 / 团队」角色进入本体。

## 开单归因优先级

1. **佣金表**：签约 → 佣金分成用户（主路径）
2. **项目负责人**：佣金缺失时回退
3. **房源维护人**：再回退

## 覆盖率（聚合）

| 指标 | 数值 |
|------|------|
| 佣金归因覆盖（已通过签约） | 约 85.5% |
| 任一经纪人可归因的成交 | 825 / 835 |
| 佣金行数（历史切片） | 约 2.7k 行级分成记录 |

## 经纪人侧特征（建模）

- 历史开单频次（T0 前窗口）
- 归属团队活跃度
- 近期跟进/带看参与强度（聚合）
- 从业时长档位（粗分桶）

## 业务问题（提示词对齐）

1. 未来窗口内，哪些经纪人更可能开单？
2. 哪些在册房源更可能成交？
3. 若成交，预期天数大致落在何区间？（时间模型难度更高，未必稳定击败中位数基线）
