# 模拟需求（写入 simulation_requirement）

请基于北京市丰台区电动自行车限行试点相关材料，构建多智能体舆论世界，并预测：

1. 不同发布策略下，政策信息会如何在市民、骑手（含房山跨区骑手）、商户、家长、自媒体之间传播，以及是否外溢到其他城区；
2. 赞成 / 反对 / 中立观点如何随时间演化；
3. 哪些关键人物或账号会成为传播引爆点；
4. 强硬发布 vs 柔性发布 vs 仅有传言（不正式发布）三种情况下，负面情绪与对立程度有何差异。

关注实体类型建议包含：政府官员、交管机构、外卖骑手、骑手协会、外卖平台、通勤市民、学生家长、沿街商户、自媒体、记者、高校专家、行政区（北京市、丰台区、房山区）、道路（丽泽路、丰台南路、南三环辅路、北京西站周边）。
