# Design System

## Theme

面向明亮办公环境和长时间分析工作的浅色产品界面。深色侧边导航用于建立稳定产品边界，主体使用无色偏的浅灰背景和白色工作面。SandOwl 橙色只用于当前选择、关键动作和少量状态强调。

## Color

- Brand: `oklch(0.65 0.24 36)`
- Brand action: `oklch(0.52 0.2 36)`
- Navigation: `oklch(0.18 0.012 255)`
- Canvas: `oklch(0.975 0.003 255)`
- Surface: `oklch(1 0 0)`
- Ink: `oklch(0.2 0.012 255)`
- Muted ink: `oklch(0.46 0.014 255)`
- Border: `oklch(0.89 0.007 255)`

## Typography

统一使用 `Inter, IBM Plex Sans, Noto Sans SC, system-ui`。界面标题和正文依靠字号、字重与间距建立层级；英文系统标识和运行编号可使用 `JetBrains Mono, ui-monospace`。

## Layout

桌面端采用固定侧边导航、粘性顶栏和最大宽度内容区。小屏幕将侧边栏重排为顶部横向导航，内容和流程图转为单列。页面间共享稳定的标题、状态与操作位置。

## Components

- 导航项：缩写标记、中文名称、英文辅助标签；当前项用品牌色和实底表达。
- 状态：圆点、文字和浅色底共同表达，不只依赖颜色。
- 流程节点：保持结构化边框和连接关系，避免装饰性卡片网格。
- 按钮：主按钮使用深品牌色，次按钮使用白底边框；所有状态使用统一圆角和焦点环。
- 地域态势：沿用 MatrAIx 地球的空间表达，但节点、数量、议题和选择状态必须来自媒体 API；地球不是装饰背景，必须同时提供可键盘操作的地域列表和文本数据等价物。
- 媒体报道：标题、媒体源、发布时间、地域、议题和摘要形成稳定扫描顺序；原文链接明确离开工作台，加载失败时保留可重试的技术诊断，不显示假数据。

## Motion

仅为悬停、选中和导航切换提供 160–200ms 状态过渡。减少动态效果模式下取消非必要过渡。
地球自动旋转只在用户未交互且系统未请求减少动态时启用；聚焦、悬停或选中地域后暂停，数据点位置和连线不得使用运行时随机数。
